1. Architecture Excel — deux zones

Chaque feuille SIMULATEUR {CONCEPT} du fichier ROD - Simulateurs + détail des coûts.xlsx est scindée en :

ZoneColonnesRôle
Gauche — PILOTE B–J Référence fixe : paramètres hôtel pilote, CA F&B / N-F&B, coefficients. Ne doit pas être « inventée » à la volée : c’est la base de projection.
Droite — SIMULATEUR L–T Hôtel cible : entrées éditables (chambres, TO, guests, m_lin / frigos, mix). Les formules projettent le pilote sur la cible (colonne O surtout).
Principe : le pilote est un mois moyen de résultat concept. L’hôtel cible n’a pas besoin d’être un pilote terrain : on applique les mêmes ratios (taux d’acheteurs, CA/vente, impact mix, surface…).

Source code : run_rules_r1_r4 + predict_from_levers dans release_1_0_0/src/sim_v1/service.py. Coefficients stockés dans v1_pilot_defaults.xlsx / sim_v1_pilot_defaults.json.

Textes « REGLE » dans Excel (équivalents commentaires) :
· R1 (B27) : « Chaque client acheteur génère du CA. » · base = résultat pilotes.
· R2 (C41–C42) : chaque 10 % de mix en plus/moins impacte F&B et N-F&B (bonus/malus vs mix de référence).
· R3 (C58) : catégorie cochée → +X % sur CA ; non cochée → −X %.
· R4 (C101–C102 / L101) : chaque m_lin (ou frigo) en plus ajoute du CA ; en moins en retire. Attention Excel : si m_lin > réf. → ajoute ; sinon retire.
· Note L72–L73 : hôtels +50 ch. avec ≥1 des 5 catégories N-F&B « lifestyle » → solution recommandée LIBERTY (voir reco.html).

4. Exemple réel pas-à-pas — projection SIMPLY

Pilote Excel SIMPLY (moyenne concept, calée sur profil type Ibis budget Nice) :

  • 129 chambres · TO 80 % · 1,7 guests/ch · 6 m_lin · mix F&B 40 %
  • 231 ventes/mois · CA HT 533 € F&B + 187 € N-F&B

Hôtel cible illustratif (profil proche Ibis budget Strasbourg / données v1_hotel_params H2075 ajusté pour lecture) :

  • 100 chambres · TO 70 % · 1,7 guests · 4 m_lin · mix F&B 70 %
Étape 0 — Clients hébergés cible
clients/mois = 100 × 0,70 × 1,7 × 30,5 = 3 629,5
R1 — Taux acheteurs & CA proportionnel
taux = 231 / 5 350,92 ≈ 0,04317
nb_acheteurs = 3 629,5 × 0,04317 ≈ 156,7
CA_F&B R1 = (533/231) × 156,7 ≈ 361,5 €
CA_N-F&B R1 = (187/231) × 156,7 ≈ 126,8 €
R2 — Écart mix (cible 0,70 vs réf. 0,40)
mix_steps = (0,70 − 0,40) × 10 = +3 pas de 10 %
Δ F&B = 133,25 × 3 = +399,75 → CA_F&B R2 ≈ 761,2 €
Δ N-F&B = 31,17 × (−3) = −93,5 → CA_N-F&B R2 ≈ 33,3 €
R3 — Catégories toutes ON (release)
F&B × 1,48 → ≈ 1 126,6 €
N-F&B × 1,33 → ≈ 44,3 €
R4 — Surface (4 m_lin vs réf. 6 → Δ = −2)
F&B − 2 × 88,83 → ≈ 948,9 €
N-F&B − 2 × 31,17 → ≈ −18,0 €
CA HT final = 948,9 + (−18,0) ≈ 930,9 € / mois
Marge produit = CA×(1−1/coeff) F&B + N-F&B ≈ ≈ 590 € / mois (détail recalculé dans le lab ci-dessous)

Ces montants sont monétaires HT mensuels « mois moyen » — annuel = × 12 côté UI estimation. Le ROI (marge − coûts) est documenté dans roi.html.
