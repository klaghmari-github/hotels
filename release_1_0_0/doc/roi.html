1. Définition officielle du ROI

ROI (mensuel ou annuel) = marge sur les ventes (prix de vente − prix d’achat, via coefficients de marge) moins les coûts de la solution (techno + annexes + agencement amorti).
ROI_mensuel = marge_produit_mensuelle − coût_solution_mensuel ROI_annuel = ROI_mensuel × 12 // Alias code (même grandeur) : marge_nette_monthly = roi_monthly marge_nette_annual = roi_annual

Fichier Excel : E176 = E134 − H168 (pilote) · O176 = O134 − R168 (simulation). Libellé B173 : « Formule = (marge produits mensuelle − coûts mensuels) ».

Les moteurs sim_v1 / sim_v2 / ml ne calculent que le CA (et la marge produit). L’enrichissement ROI est commun via enrich_prediction_with_costs.

2. Règle — marge produit à partir du CA

// Coefficients = « Marge » J9 / J10 (pilote) ou T9 / T10 (simu) // Ce ne sont pas des % de marge mais des ratios PV/PR (markup) Marge_F&B = CA_F&B − (CA_F&B / coeff_F&B) Marge_NFB = CA_NFB − (CA_NFB / coeff_NFB) Marge = Marge_F&B + Marge_NFB // Équivalent : Marge = CA × (1 − 1/coeff)

4.1 Marge nette / ROI

// Excel E176 / O176 Marge_nette = Marge_produits − Coûts_mensuels // Taux (E177) — si nette < 0 → "N/A" Taux = Marge_nette / CA_HT_total

4.2 Amortissement Excel vs payback code

Excel (B182 / E184) — libellé : « Formule = (coût total sur 60 mois / marge nette mensuelle) » :

// Excel (approximation documentée dans la feuille) Amortissement_mois = E168 / E176 // E168 = somme des totaux capex+coûts packagés affichés // E176 = marge nette mensuelle

Code release (enrich_prediction_with_costs) — payback sur le capex et le ROI mensuel :

SI marge_nette_mensuelle > 0 ET capex > 0 : payback_months = capex / marge_nette_mensuelle payback_years = payback_months / 12 SINON SI marge_nette ≤ 0 : payback = null // non amortissable / « Not profitable » SINON : payback = 0
Les deux définitions d’« amortissement » ne sont pas strictement identiques (Excel regroupe un coût total packagé 60 mois ; le code utilise le capex d’installation). Le ROI = marge − coûts est en revanche aligné.
