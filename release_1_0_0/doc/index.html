2. Moteurs

  • sim_v1 Règles Excel R1–R4 — référence pilotes, marge ventes par coeffs F&B / Non F&B. Doc : sim_v1.html.
  • sim_v2 Scénarios × pilotes — coefficients d’intensité, restitution mix. Doc : sim_v2.html · scientifique · méthodologie.
  • ml Chaîne par solution — taux de conversion → pont sim_v2 → CA final ; features hôtel, proximité, météo, marque + signaux sim_v2. Doc : ml.html.

ROI = marge ventes (PV − PA) − coûts solution — commun aux trois moteurs après le CA. Doc : roi.html.

Reco concept — arbre Excel (taille, catégories, m_lin, vitrine, TO) + choix ROI dans l’app. Doc : reco.html.

3. Évaluations

ModeTrainTestCommande / fichiers

Admin : LOO · comparaison et full · comparaison. Interprétation : analyse.html.
