2. Moteurs

  • sim_v1 — règles ROD Excel (R1–R4), référence pilotes, marge ventes par coeff F&B/Non F&B. Doc interactive : sim_v1.html.
  • sim_v2 — scénarios × pilotes, coefficients d’intensité, restitution mix.
  • ml — chaîne XGBoost par solution : taux de conversion puis CA ; features hôtel, proximité, météo, marque + signaux sim_v2.

ROI = marge ventes (PV − PA) − coûts solution. Commun aux trois moteurs après le CA. Doc : roi.html. Arbre de recommandation concept : reco.html.
