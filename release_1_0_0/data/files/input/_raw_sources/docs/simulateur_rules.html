1. Architecture & zones

Chaque simulateur Excel (Simply / Liberty / Connected) est structuré en 2 zones :

  • Zone gauche = données de référence des pilotes (moyennes fixes, non modifiables par l’utilisateur final)
  • Zone droite = simulation paramétrable (inputs hôtel → calculs en cascade)

Le moteur doit calculer les 3 solutions en parallèle à chaque changement de paramètre, puis mettre en avant la solution recommandée par l’arbre de décision.

Principe de fidélité : reproduire exactement les formules et coefficients des fichiers Excel, y compris les valeurs de référence pilotes (même si elles intègrent des ventes réception hors bornes).

// Constantes pilote (par concept) nb_ventes_pilote // 231 / 312 / 534 clients_heberges_pilote // calculés depuis ch × guests × TO × 30.5 du pilote CA_FB_pilote, CA_NFB_pilote // Simulation clients_heberges_mois = nb_chambres × guests_per_room × TO × 30.5 taux_acheteurs = nb_ventes_pilote / clients_heberges_pilote nb_acheteurs = clients_heberges_mois × taux_acheteurs CA_FB = (CA_FB_pilote / nb_ventes_pilote) × nb_acheteurs CA_NFB = (CA_NFB_pilote / nb_ventes_pilote) × nb_acheteurs

6. Règle 2 – Impact Mix (±10 %)

mix_FB_ref = 0.40 (Simply) | 0.70 (Liberty) | 0.80 (Connected) mix_NFB_ref = 1 − mix_FB_ref diff_FB = mix_FB_simule − mix_FB_ref nb_x10 = diff_FB × 10 // peut être négatif // CA de référence pour 10% (valeurs Excel zone gauche après R1, pour 10% de mix) // Simply : CA_10pct_FB ≈ 133.25 HT · CA_10pct_NFB ≈ 31.17 HT // Liberty : à dériver proportionnellement du CA pilote // Connected: CA_10pct_FB ≈ 437.875 HT · CA_10pct_NFB ≈ 65.5 HT CA_FB_add = CA_10pct_FB × nb_x10 CA_NFB_add = CA_10pct_NFB × (diff_NFB × 10) // diff_NFB = −diff_FB CA_FB_apres_R2 = CA_FB_apres_R1 + CA_FB_add CA_NFB_apres_R2 = CA_NFB_apres_R1 + CA_NFB_add

// Calcul du multiplicateur mult_FB = 1 + Σ(±coeff_i) // + si coché, − si non coché mult_NFB = 1 + Σ(±coeff_j) CA_FB_apres_R3 = CA_FB_apres_R2 × mult_FB CA_NFB_apres_R3 = CA_NFB_apres_R2 × mult_NFB
Cas limite Excel : si le CA après R2 est négatif, la formule « réduit la perte » (le signe du coefficient s’applique toujours, ce qui peut rapprocher de zéro). Implémenter le comportement additif/multiplicatif de façon cohérente et documentée.

Les 5 catégories N-F&B {Cosmetics, Kids, RTW, Accessories, Souvenirs} servent aussi à l’arbre de reco (cf. §3).

8. Règle 4 – Surface / Équipement

Simply & Liberty → mètres linéaires

ML_ref = 6 (Simply) | 8 (Liberty) diff = ML_simule − ML_ref CA_unit_FB = CA_FB_ref_R4 / ML_ref // CA unitaire par ML (valeurs Excel zone gauche) CA_unit_NFB = CA_NFB_ref_R4 / ML_ref // Simply exemples zone gauche R4 : // CA_unit_FB ≈ 88.83 HT (pour 1 ML) // CA_unit_NFB ≈ 31.17 HT SI diff < 0 : CA_FB = CA_apres_R3_FB − CA_unit_FB × |diff| CA_NFB = CA_apres_R3_NFB − CA_unit_NFB × |diff| SINON : CA_FB = CA_apres_R3_FB + CA_unit_FB × diff CA_NFB = CA_apres_R3_NFB + CA_unit_NFB × diff

Connected → nombre de frigos

Frigo_ref = 3 // frigos froid diff = nb_frigos_froid_simule − Frigo_ref // Même logique additive avec CA_unit dérivé du CA pilote / 3 CA_FB = CA_apres_R3_FB ± (CA_unit_FB × |diff|) CA_NFB = CA_apres_R3_NFB ± (CA_unit_NFB × |diff|)
Après R4 on obtient le CA final HT (F&B + N-F&B) qui alimente marge et coûts.

11. Marge nette & Amortissement

Marge_nette = Marge_produits − Coûts_mensuels_totaux SI Marge_nette < 0 : afficher « Not profitable » // ne pas afficher un taux négatif trompeur SINON : Taux_marge = Marge_nette / CA_HT_total // Amortissement (uniquement si Marge_nette > 0) cout_total_60_mois = somme des coûts one-shot amortis sur 60 mois + 60 × (licence mensuelle + annexes + agencement mensuel) // coller à la logique Excel : (coût total sur 60 mois / marge nette) Amortissement_mois = cout_total_60_mois / Marge_nette Amortissement_ans = Amortissement_mois / 12
Si CA F&B, CA N-F&B ou total est négatif après les règles → afficher « Not profitable » plutôt qu’un chiffre négatif.

12. Ordre d’exécution exact

1
Lire paramètres hôtelchambres, guests/ch, TO, ML, mix, catégories, vitrine, frigos, équipements, contrat, agencement
2
Arbre de recommandation→ solution_recommandee ∈ {Simply, Liberty, Connected}
3
Pour chaque solution S ∈ {Simply, Liberty, Connected}
  1. Règle 1 – proportionnalité clients acheteurs → CA_R1
  2. Règle 2 – ajustement mix ±10 % → CA_R2
  3. Règle 3 – coefficients catégories → CA_R3
  4. Règle 4 – ML ou frigos → CA final
  5. Marge produits (coeffs 2,6 / 1,45)
  6. Coûts Techno + Annexes + Agencement
  7. Marge nette + Amortissement (ou « Not profitable »)
4
AffichageSolution recommandée en premier · P&L des 3 solutions · possibilité de forcer une autre solution · refresh immédiat à chaque changement de paramètre

13. Garde-fous & corrections (implémenter SANS les bugs)

  1. Minimum 2 mètres linéaires — sinon message d’erreur, pas de calcul.
  2. Slider Mix F&B — pas de pas imposé à 10 %. Continu 0–100 %.
  3. Tous toggles catégories OFF — forcer mix 0 % ou message d’erreur (ne pas laisser un état incohérent).
  4. Frigo froid (Connected) — n’apparaît / n’est compté que si Mix F&B ≥ 10 %.
  5. Frigo ambiant — n’apparaît que si Mix N-F&B ≥ 10 %.
  6. Vitrine — minimum 1 obligatoire pour Simply & Liberty.
  7. Paramètre forcé par le système (pour rendre un résultat positif) → afficher en rouge #DC2C3E.
  8. Refresh — toute modification recalcule immédiatement reco + 3 P&L.
  9. Recommandation ≠ max CA — toujours l’arbre de décision en premier.
  10. Années de référence — calibrage 2023-2025 ; 2026 hors modélisation.
  11. CA / marge négatifs → « Not profitable », pas d’affichage trompeur.
  12. VAT — CA affiché en HT pour les calculs de marge ; TTC = HT × (1+TVA) pour info (TVA soft ~5,5–10 %, non-fb 20 %).
